# Hero Image Slots

Upload photos to this folder using these exact filenames.
Each slot shows a labeled placeholder until the file is present.

| File | Slot | Description |
|------|------|-------------|
| `hero-stairs-left.jpg` | Far-left accent strip | White stairs, blue rail, bougainvillea flowers — tall portrait strip |
| `hero-terrace-main.jpg` | Right background | Wide ocean terrace, wooden table, tropical fruits, blue sea, bamboo wall |
| `hero-card-suite.jpg` | Top-right floating card | Suite interior or window with ocean view |
| `hero-card-exterior.jpg` | Lower-right floating card | Exterior white/blue architecture, pousada facade |
| `hero-beach-strip.jpg` | Bottom panoramic strip | Beach, turquoise ocean, boats — wide panoramic crop |
